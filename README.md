# AWS-Secure-Direct-Connect
In this lab, I set up a Direct connect Hosted Connection. I created private virtual interfaces, (VIFs) to access resources in the VPCs, public virtual interfaces to reach public AWS services, and transit virtual interfaces to connect with Transit Gateways.
